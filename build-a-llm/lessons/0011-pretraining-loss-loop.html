预训练：教模型说话

定义"说错话"的数字（交叉熵），然后看着训练循环把损失从 9.78 压到 0.39——你亲手训练的第一个 LLM。

§1给"胡话"定价：交叉熵损失

训练需要一把数字尺子衡量输出质量。思路：看模型给正确下一个词分配的概率——越高越好。书里手工推演了全过程（图 5.7 六步），值得走一遍：

# 输入与目标：目标 = 输入右移一位（第 3 课的老朋友）
inputs  = torch.tensor([[16833, 3626, 6100],   # every effort moves
                        [40, 1107, 588]])     # I really like
targets = torch.tensor([[3626, 6100, 345],    # effort moves you
                        [1107, 588, 11311]])  # really like chocolate

logits = model(inputs)                        # [2, 3, 50257]
probas = torch.softmax(logits, dim=-1)        # 概率分布

# 模型给目标词的概率（未训练时约 1/50257 ≈ 0.00002）
target_probas = probas[0, [0,1,2], targets[0]]   # tensor([7.45e-05, 3.11e-05, 1.16e-05])

log_probas = torch.log(target_probas)            # 步骤④：取对数（好优化）
avg_log_probas = torch.mean(log_probas)          # 步骤⑤：平均
loss = -avg_log_probas                           # 步骤⑥：取负 → tensor(10.79)

这个 10.79 就是交叉熵损失（cross-entropy loss）——"负的平均对数概率"。PyTorch 一行搞定（内部还更高效）：

loss = torch.nn.functional.cross_entropy(logits.flatten(0, 1), targets.flatten())
# flatten(0,1)：[2,3,50257] → [6,50257]，[2,3] → [6]

配套的直观指标：困惑度（perplexity） = torch.exp(loss) ≈ 48,725——"模型每一步像在近 5 万个词里抓瞎"。训练目标：把这两个数压下去。

——《书》§5.1.2, pp.154–162（图 5.7）

§2备料：切分数据、构造批次

训练语料：公共领域短篇《The Verdict》（5,145 个 token——刻意小到笔记本 5 分钟可训）。90/10 切分训练/验证集，复用第 3 课的 DataLoader：

train_loader = create_dataloader_v1(train_data, batch_size=2,
    max_length=256, stride=256, drop_last=True, shuffle=True)   # 9 个批次
val_loader = create_dataloader_v1(val_data, batch_size=2,
    max_length=256, stride=256, drop_last=False, shuffle=False) # 1 个批次

还记得 stride=256=max_length 的意义吗？不重叠、省算力。训练前先量基线：train loss 10.99 / val loss 10.98——和手工推演的 10.79 一致（随机水平）。

——《书》§5.1.3, pp.162–168

三个阶段看得分明：乱标点 → 卡词重复（"and, and, and"）→ 语法通顺的英文。但注意 val loss 卡在 6.45 不动——5,145 个 token 对 124M 参数，模型第 2 个 epoch 后就开始背诵训练集（书里验证：生成的句子能在原文里逐字搜到）。这是教科书级的过拟合（overfitting）演示；真实预训练用数万亿 token，通常只训一个 epoch 就够。

——《书》§5.2, pp.168–174（图 5.12，AdamW 见 p.172）
为什么用 AdamW？Adam 的变体，改进了权重衰减（weight decay）——惩罚大权重防过拟合，LLM 训练标配。lr=4e-4 也是小数据集场景的稳妥值。参考：Loshchilov & Hutter, Decoupled Weight Decay Regularization, ICLR 2019（arXiv:1711.05101）。
