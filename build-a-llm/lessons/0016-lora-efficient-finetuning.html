LoRA：动 2% 的参数，办 100% 的事

微调 70B 模型存不下多份全量权重？低秩适应（LoRA）只训练并保存一对小矩阵——124M 参数的模型只训 266 万个，效果几乎不打折。

§1核心思想：低秩近似 ΔW

普通微调中，反向传播为每个权重矩阵 W 学一个同样大小的更新 ΔW：W' = W + ΔW。LoRA（Low-Rank Adaptation，低秩适应）的洞察（Hu et al., LoRA: Low-Rank Adaptation of Large Language Models, arXiv:2106.09685）：微调所需的 ΔW 是低秩的——可以用两个小矩阵的乘积近似：

W' = W + B·A
# W:  [768 × 768]（冻结，不动）
# A:  [r × 768]，B: [768 × r]    ← 只训练这两个小矩阵
# r（秩）≪ 768，比如 r = 16

参数账（以一层 768×768 为例）：全量微调 590K 参数；LoRA（r=16）只要 768×16 + 16×768 = 24.6K——4%。W 保持原样，"改动量"单独存放在 A、B 里。这个分离是 LoRA 在工程上最妙的地方（下一节）。

——《书》附录 E.1, pp.363–364（图 E.1）

§2实现：给 Linear 层穿外挂

class LoRALayer(nn.Module):
    def __init__(self, in_dim, out_dim, rank, alpha):
        super().__init__()
        self.A = nn.Parameter(torch.empty(rank, in_dim))     # 高斯随机初始化
        self.B = nn.Parameter(torch.zeros(out_dim, rank))    # ← 零初始化！
        self.alpha = alpha        # 缩放因子：控制 LoRA 输出的影响强度

    def forward(self, x):
        return self.alpha * (x @ self.A.T) @ self.B.T

class LinearWithLoRA(nn.Module):
    def __init__(self, linear, rank, alpha):
        super().__init__()
        self.linear = linear                     # 原层（已冻结）
        self.lora = LoRALayer(linear.in_features,
                              linear.out_features, rank, alpha)
    def forward(self, x):
        return self.linear(x) + self.lora(x)     # 原输出 + 低秩修正

replace_linear_with_lora(model, rank=16, alpha=16)   # 给模型所有 Linear 穿外挂

两个精妙细节：

  • B 初始化为零 → B·A = 0 → 穿上外挂的模型与原模型完全等价（书实测：替换后准确率 46.25%/45.00%/48.75%，与替换前分毫不差）。训练从"与原模型同一起点"出发。
  • alpha 缩放：调节低秩修正对层输出的影响强度，常取 rank 的一半、一倍或两倍。
——《书》附录 E.4, pp.369–374（列表 E.6）

§4为什么工程师爱它：一份底座，千份外挂

LoRA 矩阵与 W 分离，带来工程红利：

  • 存储：一个 70B 底座 + 每个客户/任务一个小 LoRA（几 MB），而不是几十份 140GB 的完整模型
  • 推理零开销：部署前可把 B·A 直接合并进 W（W' = W + BA），推理时就是普通模型，不多一次乘法
  • 切换灵活：不合并也行——运行时热插拔不同任务的 A、B，同一底座秒变客服模型/代码模型/翻译模型
  • 显存友好：优化器状态只为可训练参数保留——这是大模型上省显存的大头

这正是当下开源社区的现实：Hugging Face 上满地的 "base + LoRA adapter" 组合，QLoRA 等变体（底座再量化到 4-bit）把消费级显卡微调 33B 模型变成可能。
