自回归生成：让 GPT 开口说话

十几行代码实现生成循环——你会发现模型此刻满口胡话，而这正是下一章预训练的全部动机。

§1生成循环：预测 → 拼接 → 重复

回忆第 1 课的"自回归"：每生成一个词，就把它拼回输入末尾，再预测下一个。代码（书列表 4.8）：

def generate_text_simple(model, idx, max_new_tokens, context_size):
    for _ in range(max_new_tokens):                      # 生成 max_new_tokens 个新 token
        idx_cond = idx if idx.size(1) <= context_size \
                       else idx[:, -context_size:]       # ① 上下文超长则只留最后 1024 个

        logits = model(idx_cond)                         # ② 前向：[b, T, 50257]

        probs    = torch.softmax(logits[:, -1, :], dim=-1)  # ③ 只取最后一个位置 → 概率
        next_idx = torch.argmax(probs, dim=-1, keepdim=True) # ④ 贪心：挑最大概率的 token

        idx = torch.cat((idx, next_idx), dim=1)          # ⑤ 拼回输入 → 下一轮
    return idx

五步循环中藏着一个细节：logits[:, -1, :] ——我们只关心最后一个位置的预测。因为因果掩码（第 6 课）保证了最后一个位置"看完了"全部上文，它的 logits 就是对"下一个词"的判断。

——《书》§4.7, pp.141–145（列表 4.8，图 4.17–4.18）

§2贪心解码：永远选最稳的词

argmax 选最大概率 = 贪心解码（greedy decoding）。书里特意指出：softmax 是单调函数，不改变大小顺序，所以 argmax(probs) 与 argmax(logits) 结果相同——softmax 这步纯粹是为了教学直觉（书 §4.7, p.146）。贪心解码确定、保守、有点无聊：同一输入永远同一输出，且容易陷入重复。第 11 课会见到它的升级版：temperature 缩放与 top-k 采样，让生成有"创造力"。

§3亲手试跑：胡言乱语的模型

model.eval()   # 关闭 dropout 等训练期组件（推理模式）

start_context = "Hello, I am"
encoded  = tokenizer.encode(start_context)
encoded_tensor = torch.tensor(encoded).unsqueeze(0)      # [1, 4]：加 batch 维

out = generate_text_simple(model, encoded_tensor,
                           max_new_tokens=6,
                           context_size=1024)
print(tokenizer.decode(out.squeeze(0).tolist()))

Featureiman Byeswickattribute argue——书里的著名输出。架构完全正确，但权重还是随机初始化的：模型还不知道任何语言规律。让它学会说话 = 第 5 章（预训练）的全部内容，也是下一课的主题。

——《书》§4.7, pp.146–148
