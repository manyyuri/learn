训练稳定三件套：预热、衰减、裁剪

工业级训练循环的三个标配配件：学习率先热身、再收油、梯度别超速。附录 D 一章讲透。

§1学习率预热：先热身再冲刺

训练刚开始时权重是"生"的：万一开局就遇到大梯度，学习率又大，几步就能把模型推废。学习率预热（learning rate warmup）：前 N 步从很小的 initial_lr 线性爬升到 peak_lr，之后正常训练。

warmup_steps = int(0.2 * total_steps)      # 预热步数：总步数的 0.1%–20%
lr_increment = (peak_lr - initial_lr) / warmup_steps

if global_step < warmup_steps:
    lr = initial_lr + global_step * lr_increment   # 线性爬坡
else:
    lr = peak_lr                                   # （下一节：改为余弦下降）
——《书》附录 D.1, pp.355–357（图 D.1）

§2余弦衰减：逐渐收油门

训练后期如果学习率仍是大步，模型会在最小值附近越过最优区来回震荡。余弦衰减（cosine decay）：预热结束后让学习率沿半个余弦周期平滑滑落到 min_lr：

progress = (global_step - warmup_steps) / (total_steps - warmup_steps)
lr = min_lr + (peak_lr - min_lr) * 0.5 * (1 + math.cos(math.pi * progress))
# progress: 0 → 1，cos 从 +1 → −1，lr 从 peak_lr → min_lr 平滑下降

合起来就是著名的"爬坡—滑落"曲线（图 D.2）：前 20 步线性升，之后余弦降到接近零。这是 GPT-3、Llama 等大模型训练的标配形状。

——《书》附录 D.2, pp.357–359（图 D.2）

§3梯度裁剪：给梯度限速

梯度裁剪（gradient clipping）防的是第 8 课提过的梯度爆炸：若所有梯度的 L2 范数（把全部梯度拉成一个超长向量算欧氏长度）超过阈值，就整体等比例缩小到阈值。

torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
# 书中实测：最大梯度值 0.0411 → 0.0185

书里的手算例子：梯度矩阵的 L2 范数是 5，超过 max_norm=1，就乘以缩放因子 1/5——方向不变、长度归 1。注意在 train_model 里裁剪放在 backward 之后、step 之前（且预热结束后才启用）。

——《书》附录 D.3, pp.359–361

§4合体：改进版 train_model

三件套装进第 11 课的训练循环，只有三处改动：

for epoch in range(n_epochs):
    for input_batch, target_batch in train_loader:
        optimizer.zero_grad()
        global_step += 1
        # 改动 ①：动态调 lr（预热 + 余弦）
        lr = warmup_or_cosine(global_step)
        for param_group in optimizer.param_groups:
            param_group["lr"] = lr
        loss = calc_loss_batch(...); loss.backward()
        # 改动 ②：预热结束后裁剪
        if global_step > warmup_steps:
            torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        optimizer.step()          # 改动 ③：无——五步咒骨架不变！

在《The Verdict》上 15 epoch：train loss 10.93 → 0.04（依旧过拟合——数据太小，与技巧无关；三件套管的是稳，不是过拟合）。真实场景的大规模预训练里，这套配方几乎是默认起手式。

——《书》附录 D.4, pp.361–363
