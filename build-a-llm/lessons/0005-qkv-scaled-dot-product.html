第 5 课 · Build a LLM From Scratch · 对应书 §3.4

查询、键、值：给注意力装上可训练的旋钮

三个权重矩阵 W_q、W_k、W_v，让"关注谁"从固定算术变成可学习的能力——这是 GPT 真正使用的注意力。

§1数据库类比：查询、键、值

上一课的简化版有个大问题：注意力分数完全由输入向量裸点积决定——模型没有半点话语权。真正的自注意力给每个词发三个"分身"，来自数据库世界的类比（书 §3.4.1 侧栏，p.85）：

角色类比职责由谁投影而来
查询 q（query）搜索词"我想找什么"——主动打听别人的内容x · W_q
键 k（key）索引"我有什么标签"——等着被匹配x · W_k
值 v（value）存储内容"我的实际内容"——被取走的货x · W_v

注意力 = 用每个词的 q 去和所有词的 k 匹配（q·k 点积），再按匹配度取走对应的 v。三个矩阵 W_q、W_k、W_v 是可训练参数——训练让模型学会"该问什么问题、亮什么标签、交付什么内容"。

——《书》§3.4.1, pp.80–86

§2四步计算（含缩放）

x_2 = inputs[1]                                # 查询词 "journey" 的向量
d_in, d_out = 3, 2                             # 教学示例：3 维 → 2 维

W_query = torch.nn.Parameter(torch.rand(d_in, d_out))
W_key   = torch.nn.Parameter(torch.rand(d_in, d_out))
W_value = torch.nn.Parameter(torch.rand(d_in, d_out))

query_2 = x_2 @ W_query                        # ① 每个词投影出 q、k、v
keys    = inputs @ W_key                       #    全部词的键 [6, 2]
values  = inputs @ W_value                     #    全部词的值 [6, 2]

attn_scores_2 = query_2 @ keys.T               # ② q 与所有 k 点积 → 分数
# → tensor([1.2705, 1.8524, 1.8111, 1.0795, 0.5577, 1.5440])

d_k = keys.shape[-1]
attn_weights_2 = torch.softmax(attn_scores_2 / d_k**0.5, dim=-1)  # ③ 缩放 + softmax

context_vec_2 = attn_weights_2 @ values        # ④ 加权取值 → z⁽²⁾

和上一课的骨架一模一样（打分→归一→汇聚），只有两处升级：①分数从 x·x 变成 q·k；②归一前多除了一个 √d_k。

为什么除以 √d_k？（缩放点积注意力（scaled dot-product attention））

嵌入维度一大（GPT 类模型 >1000），点积的数值会水涨船高。而 softmax 对大数值的反应接近阶跃函数——最大值独占全部概率，其余几乎为零，梯度趋近于 0，训练会停滞。除以 √d_k 把分数拉回温和区间，保住可用的梯度（书 §3.4.1 侧栏，p.84）。这就是论文标题里 "Scaled Dot-Product Attention" 的由来。

——《书》§3.4.1, pp.80–86 · Attention Is All You Need, §3.2.1
两个"权重"别混淆（书 p.82 侧栏）：W_q/W_k/W_v 是权重参数——训练中优化的固定旋钮；α 是注意力权重——随输入动态变化的分数。前者是硬件，后者是实时流量。

§3封装成类

import torch.nn as nn

class SelfAttention_v1(nn.Module):
    def __init__(self, d_in, d_out):
        super().__init__()
        self.W_query = nn.Parameter(torch.rand(d_in, d_out))
        self.W_key   = nn.Parameter(torch.rand(d_in, d_out))
        self.W_value = nn.Parameter(torch.rand(d_in, d_out))

    def forward(self, x):
        keys, queries, values = x @ self.W_key, x @ self.W_query, x @ self.W_value
        attn_scores = queries @ keys.T                              # ω
        attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
        return attn_weights @ values                                # z

# v2 版仅把 nn.Parameter 换成 nn.Linear（更优的权重初始化 + 偏置选项）
class SelfAttention_v2(nn.Module):
    def __init__(self, d_in, d_out, qkv_bias=False):
        super().__init__()
        self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
    # forward 同 v1，注意 nn.Linear 自带调用 x @ W.T

两版输出不同——纯粹因为 nn.Linear 用了更讲究的初始化方案。书的练习 3.1 就是让你把 v2 的权重搬运进 v1 验证数学等价（提示：nn.Linear 以转置形式存权重）。

——《书》§3.4.2, pp.86–89（列表 3.1、3.2）
