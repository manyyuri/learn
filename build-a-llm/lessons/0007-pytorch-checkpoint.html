§2张量：五分钟上手

张量（tensor）就是多维数组：标量 0 维、向量 1 维、矩阵 2 维、更高维就叫 3D/4D 张量。创建与最常用操作：

import torch
tensor0d = torch.tensor(1)                 # 标量
tensor1d = torch.tensor([1, 2, 3])         # 向量 → dtype torch.int64
floatvec = torch.tensor([1.0, 2.0, 3.0])   # 浮点 → torch.float32（DL 默认，省内存+GPU优化）
tensor2d = torch.tensor([[1, 2, 3],
                         [4, 5, 6]])       # 矩阵 [2, 3]

tensor2d.shape          # torch.Size([2, 3])
tensor2d.reshape(3, 2)  # 重塑（不连续时自动复制）
tensor2d.view(3, 2)     # 重塑（更快，但要求内存连续）—— 第 6 课拆头用的就是它
tensor2d.T              # 转置 [3, 2]
tensor2d @ tensor2d.T   # 矩阵乘法 = .matmul()  [2, 2]
tensor1d.to(torch.float32)  # 类型转换

给 JS 开发者的类比：tensor ≈ 更严格的 TypedArray + 广播规则 + GPU 后端。你在第 6 课已经见过它的实战——(b, T, 768) 的 4D 变形与转置。

——《书》附录 A.2, pp.292–297

§3autograd：自动算梯度

训练的本质是"算出每个参数该往哪边微调"（梯度）。PyTorch 的方案：只要你对 requires_grad=True 的张量做运算，它就在后台默默画一张计算图（computational graph），记录每一步谁参与了什么运算。然后一句 loss.backward() 沿图反向应用链式法则，把所有梯度存进各参数的 .grad 属性——你全程没算过一个导数（书 A.3–A.4）。

w1 = torch.tensor([1.0], requires_grad=True)   # 声明：这个参数要学
b  = torch.tensor([0.0], requires_grad=True)
# ... 前向计算得到 loss ...
loss.backward()      # 反向传播：梯度自动存入 w1.grad、b.grad
print(w1.grad)       # tensor([-0.0898]) —— 这就是"该往哪边调"的方向
——《书》附录 A.3–A.4, pp.297–301

§4nn.Module：搭网络的积木

所有 PyTorch 模型都继承 nn.Module：在 __init__ 里声明层，在 forward 里写数据流。层的输入输出维度由你指定，权重自动随机初始化（打破对称性）并自动登记为可训练参数：

import torch.nn as nn

class NeuralNetwork(nn.Module):
    def __init__(self, num_inputs, num_outputs):
        super().__init__()
        self.layers = nn.Sequential(            # 按顺序执行的层容器
            nn.Linear(num_inputs, 30),          # 全连接层：y = xW + b
            nn.ReLU(),                          # 激活函数（非线性）
            nn.Linear(30, 20),
            nn.ReLU(),
            nn.Linear(20, num_outputs),
        )
    def forward(self, x):
        return self.layers(x)

model = NeuralNetwork(50, 3)
print(model)                                     # 打印结构摘要
sum(p.numel() for p in model.parameters())       # 2213 个可训练参数
# model(x) 会自动调用 forward —— 不用写 model.forward(x)

你写过的 SelfAttention_v1、MultiHeadAttention 全是这个套路——现在回头看第 5、6 课的类，是不是豁然开朗？

——《书》附录 A.5, pp.301–306（列表 A.4）

§5DataLoader 与训练循环：五步咒语

Dataset（怎么取一条样本）+ DataLoader（怎么打包成批）负责喂数据（你在第 3 课已经用过）。而所有 PyTorch 训练循环都是同一句五步咒语，值得背下来：

loss_fn   = nn.BCELoss()                          # 损失函数：量化"错多少"
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)   # 优化器：怎么调

for epoch in range(num_epochs):
    for batch in dataloader:
        optimizer.zero_grad()     # ① 清空上轮梯度（否则会累加！）
        out  = model(x)           # ② 前向：算出预测
        loss = loss_fn(out, y)    #    算损失
        loss.backward()           # ③ 反向：autograd 算梯度
        optimizer.step()          # ④ 更新参数 w -= lr * grad
                                  # ⑤ 下一轮，直到 epoch 耗尽
存取模型（第 12 课会用到）：训练产物是 state_dict——参数名到张量的字典。torch.save(model.state_dict(), "model.pth") / model.load_state_dict(torch.load("model.pth"))（书 A.8）。搬设备：model.to(device)，Mac 上 device = "mps"（若可用）。
——《书》附录 A.6–A.8, pp.307–318
