GPT 骨架：配置、LayerNorm、GELU、残差

定好 GPT-2 124M 的完整配置，实现四个小零件。这一课结束，Transformer 块的备件就齐了。

§1一张配置表，定义整个模型

好消息：GPT 的架构出奇地简单——大部分组件是重复的。整个模型由一个配置字典驱动（书 §4.1）：

GPT_CONFIG_124M = {
    "vocab_size": 50257,    # BPE 词表大小（第 3 课）
    "context_length": 1024, # 最大上下文长度（位置嵌入行数）
    "emb_dim": 768,         # 嵌入维度（每 token 768 维向量）
    "n_heads": 12,          # 注意力头数（第 6 课）
    "n_layers": 12,         # Transformer 块堆叠层数
    "drop_rate": 0.1,       # dropout 率
    "qkv_bias": False,      # q/k/v 投影不加偏置（沿用 GPT-2 规范）
}

为什么选 124M（GPT-2 最小杯）？OpenAI 公开了它的预训练权重（第 12 课加载），笔记本就能跑；GPT-3 架构与之几乎相同，只是放大到 1750 亿参数——单个消费级 GPU 要训 665 年（书 §4.1 侧栏，p.111）。架构一模一样，改变的只是数字——这就是"可扩展架构"的含义。

——《书》§4.1, pp.109–116（列表 4.1）

§2零件 1：LayerNorm——给激活定规矩

深层网络训练的大敌：梯度消失/爆炸（vanishing/exploding gradients）——激活值逐层漂移，训练失稳。层归一化（LayerNorm）的做法：对每个 token 的 768 维激活，统一调成均值 0、方差 1，再交给两个可训练参数重新缩放平移：

class LayerNorm(nn.Module):
    def __init__(self, emb_dim):
        super().__init__()
        self.eps = 1e-5                                   # 防除零的小常数
        self.scale = nn.Parameter(torch.ones(emb_dim))    # γ 可训练
        self.shift = nn.Parameter(torch.zeros(emb_dim))   # β 可训练

    def forward(self, x):
        mean = x.mean(dim=-1, keepdim=True)
        var  = x.var(dim=-1, keepdim=True, unbiased=False)  # 有偏方差：÷n（兼容 GPT-2）
        norm_x = (x - mean) / torch.sqrt(var + self.eps)
        return self.scale * norm_x + self.shift
为什么用 LayerNorm 而不是 BatchNorm（书 p.122 侧栏）？BatchNorm 沿批维度归一化，对批量大小敏感；LayerNorm 对每个样本独立按特征维归一化——分布式训练、小批量、单条推理全都稳定。LLM 清一色选它。另外注意 dim=-1 的巧思：不管张量是 2D 还是 [batch, token, emb_dim] 的 3D，永远作用于最后一维（嵌入维）。
——《书》§4.2, pp.116–122（列表 4.2）

§3零件 2：GELU——更聪明的激活函数

ReLU 把负数一刀切为零——简单粗暴，但零点有个"尖角"，且负值神经元彻底躺平。GPT 用GELU（Gaussian Error Linear Unit）：平滑曲线，负值也有微小的非零输出（约 −0.17 的谷底），梯度处处可用。书里用 GPT-2 同款的 tanh 近似式：

class GELU(nn.Module):
    def forward(self, x):
        return 0.5 * x * (1 + torch.tanh(
            torch.sqrt(torch.tensor(2.0 / torch.pi)) *
            (x + 0.044715 * torch.pow(x, 3))
        ))
——《书》§4.3, pp.122–124（列表 4.3）

§4零件 3：前馈网络 FFN——先扩张 4 倍再压缩

class FeedForward(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(cfg["emb_dim"], 4 * cfg["emb_dim"]),  # 768 → 3072（扩 4 倍）
            GELU(),
            nn.Linear(4 * cfg["emb_dim"], cfg["emb_dim"]),  # 3072 → 768（压回）
        )
    def forward(self, x):
        return self.layers(x)      # [b, T, 768] → [b, T, 768]，形状不变

分工记住一句话：注意力负责词与词之间的交流，FFN 负责每个词独立地深加工（书 §4.5, p.132）。升维 4 倍 = 在更宽敞的空间里做非线性变换，再压回来——这是 Transformer 的标准配方。

——《书》§4.3, pp.124–127（列表 4.4）

§5零件 4：残差连接——梯度的生命线

快捷连接（shortcut / residual connection）：把一层的输入直接加到更深层的输出上（x = x + layer(x)）。它为反向传播的梯度开了一条高速公路，梯度可以绕过深层的连乘直接流回浅层——这就是 ResNet 治好梯度消失的药方。书里的 5 层对比实验（平均绝对梯度）：

层无残差有残差
layers.0（最浅）0.0002 ⚠️ 几乎消失0.2217 ✅ 健康
layers.4（最深）0.00501.3259 ✅

无残差时浅层梯度比深层小 25 倍——最需要学习的层反而学不动。有残差后各层梯度量级一致。

——《书》§4.4, pp.127–131（列表 4.5，图 4.12）
