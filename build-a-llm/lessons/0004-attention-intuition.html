第 4 课 · Build a LLM From Scratch · 对应书 §3.1–3.3

注意力的直觉：一个词该关注谁？

不用任何可训练权重，只用向量点积，你将亲手算出第一个自注意力——这是理解 GPT 全部能力的钥匙。

§1为什么需要注意力：RNN 的教训

Transformer 之前，机器翻译的主力是编码器-解码器 循环神经网络（RNN, Recurrent Neural Network）：编码器逐词读入句子，把全部含义压缩进一个"最终隐藏状态"，解码器再拿着这一个向量逐词生成翻译。

问题就出在"压缩进一个向量"：句子越长，早期信息被稀释得越厉害，长距离依赖（如主语和远处的谓语）经常丢失。2014 年的 Bahdanau 注意力给解码器开了一扇窗：生成每个词时，可以回头选择性查看输入序列的不同部分——"哪些输入对当前这个词更重要"。2017 年，研究者更进一步：把 RNN 扔掉，注意力本身就是全部——这就是 Transformer（书 §3.1–3.2）。

——《书》§3.1–3.2, pp.66–70

§2"自"注意力：句内自查

自注意力（self-attention）的"自"，指一个序列自己内部互相打量：每个词计算自己的表示时，会参考句中所有其他词与它的相关性。目标是给每个输入 x⁽ⁱ⁾ 算出一个上下文向量（context vector） z⁽ⁱ⁾——一个"吸收了全句信息"的增强版嵌入。

用书的例句（每词已嵌入为 3 维向量）：

inputs = torch.tensor([
  [0.43, 0.15, 0.89],  # x⁽¹⁾ Your
  [0.55, 0.87, 0.66],  # x⁽²⁾ journey
  [0.57, 0.85, 0.64],  # x⁽³⁾ starts
  [0.22, 0.58, 0.33],  # x⁽⁴⁾ with
  [0.77, 0.25, 0.10],  # x⁽⁵⁾ one
  [0.05, 0.80, 0.55],  # x⁽⁶⁾ step
])

我们来为 "journey"（x⁽²⁾）计算 z⁽²⁾。三步走：

第 1 步 · 打分：点积衡量相似度

用 x⁽²⁾ 当查询（query），与每个词做点积（dot product），得到注意力分数（attention score） ω：

query = inputs[1]
attn_scores_2 = torch.empty(6)
for i, x_i in enumerate(inputs):
    attn_scores_2[i] = torch.dot(x_i, query)
# → [0.9544, 1.4950, 1.4754, 0.8434, 0.7070, 1.0865]

点积越大，两个向量越"对齐"——"journey" 与 "starts"（1.4754）关系紧密，与 "one"（0.7070）关系疏远。点积就是注意力世界的相似度尺子。

第 2 步 · 归一化：分数变权重

把分数除以总和（或用 softmax，实践中永远用 softmax——对极端值更稳、梯度性质更好），得到和为 1 的注意力权重（attention weight） α：

attn_weights_2 = torch.softmax(attn_scores_2, dim=0)
# → [0.1385, 0.2379, 0.2333, 0.1240, 0.1082, 0.1581]   总和 = 1

第 3 步 · 加权求和：信息汇聚

用权重把所有词的向量加权平均，得到 z⁽²⁾：

context_vec_2 = attn_weights_2 @ inputs    # → [0.4419, 0.6515, 0.5683]

z⁽²⁾ 现在不再是孤立的 "journey"，而是吸收了 "Your / starts / with / one / step" 信息的融合向量——这就是"理解了上下文的词"。

——《书》§3.3.1, pp.71–77（图 3.8–3.10）

§3一步到位：矩阵化

上面是给一个词算 z。给所有词同时算，只需把循环换成矩阵乘法（快得多，GPU 友好）：

attn_scores = inputs @ inputs.T              # 6×6：所有查询-键点积
attn_weights = torch.softmax(attn_scores, dim=-1)  # 每行归一化
all_context_vecs = attn_weights @ inputs     # 6×3：每个词的上下文向量

注意 attn_scores 的形状 6×6：第 i 行 j 列 = 词 i 对词 j 的关注程度。这个方阵就是注意力的"心电图"，下一课的因果掩码、多头拆分全发生在它身上。

——《书》§3.3.2, pp.77–79

§4检索练习

本课的胜利：你能白板推导简化版自注意力：点积打分 → softmax 归一 → 加权求和，并解释为什么点积能当相似度尺子。这是面试"讲讲注意力机制"的地基。
