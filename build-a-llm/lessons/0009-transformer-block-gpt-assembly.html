第 9 课 · Build a LLM From Scratch · 对应书 §4.5–4.6

总装：从 TransformerBlock 到完整 GPT

30 行代码装出 1.24 亿参数的 GPT-2，并解开一个数字谜题：163M 与 124M 之差。

§1TransformerBlock：注意力的上层建筑

把第 6 课的注意力、第 8 课的零件组装起来。数据流是Pre-LayerNorm 风格（GPT-2 用它，比原始 Transformer 的 Post-LN 训练更稳，书 p.134）：

class TransformerBlock(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.att  = MultiHeadAttention(          # 第 6 课的最终版
            d_in=cfg["emb_dim"], d_out=cfg["emb_dim"],
            context_length=cfg["context_length"],
            num_heads=cfg["n_heads"],
            dropout=cfg["drop_rate"], qkv_bias=cfg["qkv_bias"])
        self.ff   = FeedForward(cfg)             # 第 8 课：768→3072→768
        self.norm1 = LayerNorm(cfg["emb_dim"])
        self.norm2 = LayerNorm(cfg["emb_dim"])
        self.drop_shortcut = nn.Dropout(cfg["drop_rate"])

    def forward(self, x):
        shortcut = x                             # ─┐ 残差 1
        x = self.norm1(x)                        #  │ Pre-LN
        x = self.att(x)                          #  │ 注意力（词间交流）
        x = self.drop_shortcut(x)                #  │
        x = x + shortcut                         # ─┘

        shortcut = x                             # ─┐ 残差 2
        x = self.norm2(x)                        #  │ Pre-LN
        x = self.ff(x)                           #  │ FFN（逐词深加工）
        x = self.drop_shortcut(x)                #  │
        x = x + shortcut                         # ─┘
        return x                                 # [b, T, 768] → [b, T, 768]

关键设计：形状全程不变（[2, 4, 768] 进，[2, 4, 768] 出）。每个输出向量仍对应一个输入 token，但内容已融合全句上下文。形状不变 = 可无限堆叠。

——《书》§4.5, pp.131–135（列表 4.6）

§2GPTModel：三十行的摩天大楼

class GPTModel(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.tok_emb = nn.Embedding(cfg["vocab_size"], cfg["emb_dim"])       # 第 3 课
        self.pos_emb = nn.Embedding(cfg["context_length"], cfg["emb_dim"])   # 第 3 课
        self.drop_emb = nn.Dropout(cfg["drop_rate"])
        self.trf_blocks = nn.Sequential(
            *[TransformerBlock(cfg) for _ in range(cfg["n_layers"])])        # × 12 层
        self.final_norm = LayerNorm(cfg["emb_dim"])
        self.out_head = nn.Linear(cfg["emb_dim"], cfg["vocab_size"], bias=False)

    def forward(self, in_idx):                       # in_idx: [b, T] token IDs
        batch_size, seq_len = in_idx.shape
        tok_embeds = self.tok_emb(in_idx)            # [b, T, 768]
        pos_embeds = self.pos_emb(torch.arange(seq_len))
        x = tok_embeds + pos_embeds                  # 嵌入 + 位置（第 3 课收官）
        x = self.drop_emb(x)
        x = self.trf_blocks(x)                       # 12 × TransformerBlock
        x = self.final_norm(x)
        return self.out_head(x)                      # logits: [b, T, 50257]

model = GPTModel(GPT_CONFIG_124M)
logits = model(batch)      # batch: [2, 4] → logits: [2, 4, 50257]

对每个位置，输出一个 50257 维的 logits（logits） 向量——词表里每个 token 的"下一词得分"。我们实现的第 2 课管道、第 3 课注意力、第 8 课零件，在这一刻全部接通。

——《书》§4.6, pp.135–139（列表 4.7）

§3参数谜题：163M vs 124M

sum(p.numel() for p in model.parameters()) 数出 163,009,536。但 GPT-2 官方是 1.24 亿。差的 39M 在哪？权重绑定（weight tying）：

  • tok_emb.weight 形状 [50257, 768] —— 查表：ID → 向量
  • out_head.weight 形状 [50257, 768] —— 打分：向量 → 词表 logits

两个矩阵形状完全相同！原始 GPT-2 干脆共用同一个矩阵（一个当"字典"一个当"打分器"）：163M − 50257×768 ≈ 124,412,160 —— 对上了。书中实现保留独立两层（训练效果更好，现代 LLM 也常这样做），第 12 课加载 OpenAI 权重时会真正启用绑定。附带一笔账：163M 参数 × 4 字节（float32）= 621.83 MB——"小"模型也不小。

——《书》§4.6, pp.139–141
