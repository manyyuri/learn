## 授课协议（每课必做）
1. **开场检索**：每课开头放 2–3 道上一课的回忆题（间隔重复 spacing + 检索练习 retrieval）
2. **单一胜利**：每课只有一个可带走的"具体成果"，控制在一屏一屏短小段落
3. **测验选项等长**：同一题的所有选项字数相同（中文按字符数），不给格式线索
4. **引用**：所有知识点标注来源（书页码 / arXiv / 官方仓库），提高可信度
5. **术语一致**：所有课程使用 `reference/glossary.html` 中的标准译法，新课新增术语必须同步更新术语表
6. 课后附"问老师"提示框 + 主推资源（最高质量的一个）
