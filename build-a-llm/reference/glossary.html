核心术语表

全部 16 课统一使用此表的译法。按主题分组，覆盖全书。

术语后的 第N课 表示该术语首次深入讲解的课程；★ 为核心概念，值得反复回顾。

一、宏观图景（第 1 课）

大型语言模型 (LLM, Large Language Model) 第1课
基于深度神经网络、在海量文本上训练的模型，用来理解和生成人类语言。
下一个词预测 (next-token prediction) 第1课 ★
GPT 的核心预训练任务：给定前文，预测接下来的词。所有能力都从这一个任务生长出来。
自监督学习 (self-supervised learning) 第1课
无需人工标注，用数据自身结构生成标签（"下一个词"即天然标签）。LLM 规模化的根本。
预训练 (pretraining) 第1课 · 第11课实操
在大型未标注语料上训练的第一阶段，产出基础模型。
基础模型 (foundation model) 第1课
预训练产出的通用模型，一切微调的起点。
微调 (finetuning) 第1课 · 第13/14/16课
在较小有标注数据集上继续训练基础模型，适配具体任务。
对齐 (alignment / RLHF) 第1课
用 RLHF/DPO 等方法调整模型行为使其有用、安全。ChatGPT = GPT 底座 + 指令微调 + 对齐。
Transformer (Transformer) 第1课
2017 年《Attention Is All You Need》提出的架构（arXiv:1706.03762）。GPT 只用其解码器。
自回归 (autoregressive) 第1课 · 第10课 ★
用自己生成的输出作为下一步输入，逐词滚动生成。预测 → 拼接 → 重复。

二、分词与嵌入（第 2–3 课）

词元 (token) 第1课 · 第2课深入
模型读取文本的最小单元：单词、子词或标点。
分词 (tokenization) 第2课
把文本切成 token 的过程；每个 token 映射为词表中的整数 ID。
字节对编码 (BPE, Byte Pair Encoding) 第3课 ★
从字符开始反复合并高频对构建词表的子词算法；GPT-2 词表 50257 个 token，tiktoken 实现。
嵌入 / 词嵌入 (embedding) 第2课概念 · 第3课实操
把离散 ID 映射为连续稠密向量的查表操作（nn.Embedding）。GPT-2 中每 token 是 768 维向量。
位置嵌入 (positional embedding) 第3课 ★
为每个位置学习的向量，加到词嵌入上注入顺序信息——注意力本身对顺序不敏感。
滑动窗口 (sliding window) 第3课
把长文本切成定长训练样本的方法。stride=max_length 时窗口不重叠，最省算力。
特殊词元 (special tokens) 第2课
<|unk|>（未登录词）、<|endoftext|>（文档结束，ID 50256——后被复用为填充符与停止符）。

三、注意力机制（第 4–6 课）

自注意力 (self-attention) 第4课 ★
序列中每个词按与其他词的相关度加权聚合信息。三步：打分 → softmax → 加权求和。
上下文向量 (context vector) 第4课
自注意力的输出：融合了全序列信息的加权表示。
查询 / 键 / 值 (query, key, value) 第5课 ★
数据库类比：query 提问，key 是索引，value 是内容。q·k 算相关性，对 v 加权求和。
缩放点积注意力 (scaled dot-product attention) 第5课 ★
Attention(Q,K,V) = softmax(QKᵀ/√d_k)·V。除以 √d_k 防大点积把 softmax 推饱和、梯度消失。
因果掩码 (causal mask) 第6课 ★
把未来位置注意力得分设为 −∞，softmax 后归零——让 token 只能看过去，保证逐词生成的可训练性。
随机失活 (dropout) 第6课
训练时随机置零部分激活（GPT-2 用 0.1）防过拟合；推理时（model.eval()）关闭。
多头注意力 (multi-head attention) 第6课 ★
一次大投影后拆成多个头（768÷12=64 维/头）各自算注意力再拼接——多视角并行。
缓冲区 (register_buffer) 第6课
随模型保存但不训练的张量（如掩码），随 .to(device) 自动搬家。

四、GPT 架构（第 8–10 课）

层归一化 (LayerNorm) 第8课 ★
把每个 token 的激活归一化为均值 0 方差 1，再用可训练 γ/β 缩放平移。稳定深层训练。
GELU (Gaussian Error Linear Unit) 第8课
GPT 的平滑激活函数（tanh 近似式），负值有小输出、梯度处处可用，优于 ReLU 的尖角。
前馈网络 (FeedForward / FFN) 第8课 ★
逐 token 独立深加工的小网络：768 → 3072 → 768（扩 4 倍再压回）。与注意力分工：词间交流 vs 逐词加工。
残差连接 / 快捷连接 (residual / shortcut connection) 第8课 ★
x = x + layer(x)：给梯度开高速公路，治深层网络的梯度消失（ResNet 药方）。
前置层归一化 (Pre-LayerNorm) 第9课
归一化放在子层之前的排布（GPT-2 用），比原始 Post-LN 训练更稳。
权重绑定 (weight tying) 第9课 ★
输出层复用词嵌入矩阵（都是 [50257, 768]）：163M → 124M。GPT-2 原版设计。
Logits (logits) 第9课 ★
softmax 前的未归一化得分。GPT 输出 [batch, T, 50257]：每个位置对全词表打分。
贪心解码 (greedy decoding) 第10课
永远 argmax 选最大概率词：确定、保守、易重复。softmax 单调故可省略。

五、训练与解码（第 7、11–12 课）

张量 (tensor) 第7课
多维数组：标量 0 维、向量 1 维、矩阵 2 维……PyTorch 的基本数据容器。
自动微分 (autograd) 第7课 ★
对 requires_grad=True 的张量记录计算图；loss.backward() 自动算梯度存入 .grad。
训练循环五步 (training loop) 第7课 ★
zero_grad → forward → loss → backward → step。全书所有训练共用此骨架。
交叉熵损失 (cross-entropy loss) 第11课 ★
负的平均对数概率。目标词概率越接近 1 损失越接近 0；ignore_index=-100 可屏蔽指定位置。
困惑度 (perplexity) 第11课
exp(loss)：模型每一步"抓瞎的有效词表大小"。越小越好。
过拟合 (overfitting) 第11课 ★
train loss 降而 val loss 停滞：模型在背诵训练集。第 11 课的教科书级演示。
AdamW (AdamW optimizer) 第11课
解耦权重衰减的 Adam 变体（arXiv:1711.05101），LLM 训练标配。
温度缩放 (temperature scaling) 第12课 ★
softmax 前 logits 除以 T：T<1 更尖锐（保守），T>1 更平坦（放飞，pizza 时刻）。
Top-k 采样 (top-k sampling) 第12课 ★
只保留 logits 最高的 k 个候选（其余 −∞ 归零），再按概率采样——创意加护栏。
状态字典 (state_dict) 第12课
层名 → 参数张量的字典；torch.save/load 的标准载体。续训要连优化器状态一起存。

六、微调与高效训练（第 13–16 课）

分类微调 (classification finetuning) 第13课
换 2 维输出头、冻结主干只解冻尾部，训练输出固定类别。专才模型。
填充 (padding) 第13课
把变长样本补齐到等长（token ID 50256），批处理的前提。
Alpaca 提示样式 (Alpaca prompt style) 第14课
### Instruction / ### Input / ### Response 三段式指令模板（斯坦福 Alpaca 首创）。
整理函数 (collate function) 第14课 ★
把样本列表组装成批的函数；指令微调自定义 collate：按批内最长 pad + 目标中 -100 屏蔽。
LLM 评审 (LLM-as-judge) 第14课
用另一个 LLM（如 Llama 3）给生成回答打分（0–100）的自动评估法（AlpacaEval 思路）。
学习率预热 (learning rate warmup) 第15课
前 N 步（总步数 0.1%–20%）从极小 lr 线性爬升到峰值，防开局大更新。
余弦衰减 (cosine decay) 第15课
预热后学习率沿半余弦周期平滑降到 min_lr，防后期震荡越过最小值。
梯度裁剪 (gradient clipping) 第15课
梯度 L2 范数超阈值（常用 1.0）就等比例缩小——方向不变、长度受限。backward 后、step 前。
低秩适应 (LoRA, Low-Rank Adaptation) 第16课 ★
W' = W + BA：冻结 W，只训小矩阵对（r≪d）。参数省 ~50 倍，推理可零开销合并（arXiv:2106.09685）。
秩 (rank, r) 第16课
LoRA 的核心超参：A/B 的内部维度，表达力与参数量的旋钮（书用 r=16，alpha=16）。
