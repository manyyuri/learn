三、前向数据流（含张量形状）

以 batch=2、序列长 T=4 为例：

输入 token IDs                [2, 4]
  │ tok_emb 查表               → [2, 4, 768]     (词嵌入)
  │ pos_emb 查表 (0..T-1)      → [2, 4, 768]     (位置嵌入)
  │ x = tok + pos              → [2, 4, 768]
  │ dropout(0.1)
  ├─ ×12 TransformerBlock（形状全程不变）
  │    │ LayerNorm(dim=-1)                     每 token 768 维归一化
  │    │ MultiHeadAttention: QKV 投影→拆12头→缩放点积(√64)→因果掩码→拼回→out_proj
  │    │ x = x + attn(x)                       残差 1
  │    │ LayerNorm
  │    │ FeedForward: 768 → 3072 → GELU → 768  扩4倍再压回
  │    │ x = x + ffn(x)                        残差 2
  │ final LayerNorm            → [2, 4, 768]
  └ out_head: Linear(768→50257) → [2, 4, 50257] logits（每位置对全词表打分）

五、生成循环（自回归）

for _ in range(max_new_tokens):
    idx_cond = idx[:, -context_size:]           # 超长只留最后 1024
    logits = model(idx_cond)
    probs  = softmax(logits[:, -1, :] / T)      # 最后一个位置 = 下一词预测
    # 可选 top-k：低于第 k 大的 logits → -inf
    next_idx = multinomial(probs, 1)            # 或 argmax（贪心 / T→0）
    idx = cat((idx, next_idx), dim=1)           # 拼回 → 下一轮
