自注意力：从直觉到公式

第 4–6 课的全部核心浓缩在一页。对应书第 3 章（pp.64–108）。

一、一句话原理

每个词的新表示 = 按相关性加权聚合序列中所有词的旧表示。相关性由点积衡量。

二、演化阶梯

阶段机制痛点
RNN / LSTM逐步传递隐状态长序列信息遗忘；无法并行
简化自注意力（第4课）x·xᵀ 打分 → softmax → 加权求和没有可训练参数
可训练自注意力（第5课）引入 W_q/W_k/W_v点积过大 → softmax 饱和
缩放点积（第5课）÷ √d_k还能看到未来 → 泄漏
因果注意力（第6课）+ 上三角 −∞ 掩码单视角
多头注意力（第6课）12 头并行（各 64 维）+ dropout—（GPT 最终形态）

三、核心公式

得分:   s = x_q · x_k                    （相关度，第4课 0.9544 的直觉）
权重:   α = softmax(s / √d_k)           （第5课：防饱和；d_k=每头维度64）
输出:   z = Σ α_i · v_i                 （加权求和）

合体:   Attention(Q,K,V) = softmax(QKᵀ/√d_k) · V
        Q = X·W_q,  K = X·W_k,  V = X·W_v

因果版: scores.masked_fill(mask, -inf)  （上三角掩码，softmax 后未来=0）
多头:   先投影 [b,T,768] → view 拆 12×[b,T,64] → 各自注意力 → 拼回 → out_proj

四、q / k / v 数据库类比

角色来源
Query 查询"我在找什么"当前词的投影
Key 键"我能提供什么标签"所有词的投影
Value 值"我的实际内容"所有词的投影

q·k 匹配度决定从各 v 拿多少信息。

五、为什么要 √d_k

点积是 d_k 项乘积之和，方差随 d_k 线性增长。大点积 → softmax 输出接近 one-hot → 梯度≈0（回忆 sigmoid 饱和）。除以 √d_k 把方差拉回 1，梯度健康。这是面试高频题。

六、因果掩码为什么是 −∞

e^−∞ = 0：softmax 天然归零，无需额外处理；未来 token 权重恰为 0，逐词生成的自回归训练才成立。top-k 采样（第 12 课）屏蔽非候选词用的同一招。
