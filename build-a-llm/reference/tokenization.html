从文字到张量：完整管道

第 2–3 课的内容浓缩。对应书第 2 章（pp.27–64）。

一、管道总览

"Hello, world!"
  → 分词器 tokenize      （BPE：子词切分）
  → token IDs [15496, 11, 995]
  → 嵌入查表 nn.Embedding(50257, 768)   → [T, 768]
  → + 位置嵌入 pos_emb[0..T-1]          → [T, 768]
  → 送入 Transformer（第 8-9 课）

二、三种分词方案对比

方案词表大小未知词处理代表
词级 word-based巨大（书例 1130）<|unk|>SimpleTokenizerV1
字符级 char-based极小（~256）无此问题—
子词 BPE中等（50257）拆到字节必能表示tiktoken / GPT-2

三、BPE 要点

  • 从字符出发，反复合并语料中最高频的相邻对，直到词表满（50257）
  • 常见词成整体 token，罕见词拆成子词——兼顾词表大小与序列长度
  • 字节级实现：任何 UTF-8 文本都能编码，永不出现 <|unk|>
  • tiktoken 用法：enc = tiktoken.get_encoding("gpt2"); ids = enc.encode(text)

四、特殊 token

tokenID用途（书中出现处）
<|endoftext|>50256文档分隔（第2课）→ 填充符（第13/14课）→ 生成停止符（第12课）——一符三用
<|unk|>（SimpleTokenizerV1 教学用）未登录词占位（第2课）

五、训练样本构造：滑动窗口

token IDs: [t1 t2 t3 t4 t5 t6 ...]
max_length=4, stride=4:
  样本1: x=[t1 t2 t3 t4]  y=[t2 t3 t4 t5]   ← y 是 x 右移一位
  样本2: x=[t5 t6 t7 t8]  y=[t6 t7 t8 t9]
Dataset + DataLoader(batch_size=4, shuffle=True) → [4, 4] 的输入/目标对

stride=max_length：窗口不重叠，省算力（预训练惯例）；stride<max_length：重叠窗口，小数据集多产样本。
