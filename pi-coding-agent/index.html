pi-coding-agent 架构课

目标：你已用 SDK 做出固定流程软件开发工作流应用，本课把这些架构机器真正讲透——从最内层的 agent 循环一路到驾驶舱，最后用回你的 workflow。

怎么用：按顺序读；每课 15–25 分钟，含测验（点选项即时反馈）与「一手阅读」源码清单。全部内容经源码核实。语言：中文，术语保留英文。
