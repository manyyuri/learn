资源加载：extensions / skills / prompts 从哪来

session 用的工具、系统提示词里的技能、/命令、AGENTS.md 上下文……这些「资源」不是写死的，而是由 ResourceLoader 在启动时从项目目录和全局目录发现出来的。这一课看清发现规则，以及你如何注入 override。

本课成果：知道默认发现规则（项目 vs 全局、哪些目录被扫），理解 ResourceLoader 的「reload 一次、读四次」形态，并会用 override 钩子把自定义资源塞进加载结果。

1. 谁加载什么

createAgentSession() 不直接读磁盘——它从一个 ResourceLoader 拿资源。默认是 DefaultResourceLoader，职责（reload 后可取）：

资源getter用途
扩展 ExtensionsgetExtensions()注册工具 / 命令 / 事件监听 / provider（.ts 文件，经扩展加载器执行）
技能 SkillsgetSkills()SKILL.md，注入系统提示词供 agent 调用（配了读文件工具时）
提示模板 PromptsgetPrompts()/命令 的展开来源
主题 ThemesgetThemes()TUI 视觉
上下文文件 ContextgetAgentsFiles()AGENTS.md / CLAUDE.md，参与组装系统提示词

2. 默认发现规则

两个根：项目 cwd 与全局 agentDir（默认 ~/.pi/agent，用 getAgentDir() 取）：

资源项目侧 (cwd)全局侧 (agentDir)
extensions.pi/extensions/extensions/
skills.pi/skills/、.agents/skills/（含祖先目录，到 git 根为止）skills/、~/.agents/skills/
prompts.pi/prompts/prompts/
context filesAGENTS.md（从 cwd 向上找，还认 AGENTS.override.md/CLAUDE.md）全局 AGENTS.md

上下文文件候选列表（源码核实）：AGENTS.override.md → AGENTS.md → CLAUDE.md，逐级向上直到 git 根或文件系统根。

技能为何「需要读文件工具」才注入：SKILL.md 通常很大，塞进提示词浪费窗口。system-prompt 组装时（system-prompt.ts）只在有 read 类工具时把技能清单注入，让 agent 按需去读文件——这是上下文经济的细节设计。

3. 扩展能做什么（ExtensionAPI）

扩展是一个工厂函数 (pi) => {…}，拿到的 pi（ExtensionAPI，源码 loader.ts）至少含：

  • pi.on(event, handler) —— 订阅生命周期事件（agent_start/agent_end/tool 相关…）
  • pi.registerTool(tool) —— 注册工具（复用 ToolDefinition 形态，见第 3 课）
  • pi.registerCommand(name, options) —— 注册 /命令
  • pi.registerProvider(...) —— 注册自定义 model provider

扩展还可以 pi.sendMessage 主动发起一轮 agent、注入自定义消息（custom 角色）等。扩展文件经加载器做模块解析后执行，errors 会收集为 { path, error } 列表。

4. 用 override 钩子改加载结果

SDK 里你不必真在磁盘放文件——DefaultResourceLoader 构造选项提供纯代码注入点：

const loader = new DefaultResourceLoader({
  systemPromptOverride: (base) => `${base}\n\nBe concise.`,  // 改系统提示词
  skillsOverride:      (cur) => ({ ...cur, skills: [...cur.skills, customSkill] }),
  agentsFilesOverride: (cur) => ({ ...cur, agentsFiles: [...cur.agentsFiles, virtualFile] }),
  promptsOverride:     (cur) => ({ ...cur, prompts: [...cur.prompts, customCommand] }),
  extensionFactories:  [ (pi) => { pi.on("agent_start", …); } ],  // 内联扩展
  additionalExtensionPaths: ["/path/to/ext.ts"],
});
await loader.reload();
const { session } = await createAgentSession({ resourceLoader: loader });

想完全掌控（不要任何磁盘发现）：每个 getter 都可返回空，配 tools/customTools 只开你要的——这就是 SDK 示例 12-full-control.ts 做的事。注意 reload() 是异步的，必须在 createAgentSession 前 await。
