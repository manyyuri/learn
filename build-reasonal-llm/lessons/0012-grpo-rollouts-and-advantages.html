01训练集：12000 道数学题

MATH 全集 12,500 题 = MATH-500（评估）+ 12,000 训练题，两块互不重叠——防数据泄漏，和第 5 课的教训呼应BRM §6.4。每题字段：`problem`（prompt）、`answer`（验证目标）、`solution`（参考解法，训练不用——不想把模型锁死在特定解法风格上，让它自由探索解空间）。

02阶段一：采样 rollouts

为什么不能直接复用第 7 课的 generate_text_stream_concat_flex？因为它标了 @inference_mode——彻底关闭梯度追踪，之后没法 backward。训练版改用 @torch.no_grad()（只关梯度、不开推理模式）BRM §6.5：

@torch.no_grad()
def sample_response(model, tokenizer, prompt, device,
                    max_new_tokens=512, temperature=0.8, top_p=0.9):
    input_ids = torch.tensor(tokenizer.encode(prompt), device=device)
    cache = KVCache(n_layers=model.cfg["n_layers"])
    model.reset_kv_cache()
    logits = model(input_ids.unsqueeze(0), cache=cache)[:, -1]
    generated = []
    for _ in range(max_new_tokens):
        probas = top_p_filter(torch.softmax(logits / temperature, dim=-1), top_p)
        next_token = torch.multinomial(probas.cpu(), num_samples=1).to(device)
        token_id = next_token.item()
        generated.append(token_id)
        if token_id == tokenizer.eos_token_id:
            break
        logits = model(next_token, cache=cache)[:, -1]
    full_token_ids = torch.cat([input_ids, torch.tensor(generated, device=device)])
    return full_token_ids, input_ids.numel(), tokenizer.decode(generated)
    #              ↑ 完整 token 序列   ↑ prompt 长度    ↑ 答案文本

三个细节BRM §6.5：① 返回 token IDs 和 prompt 长度——后面算 sequence logprob 直接用，不用重新分词；② 回答里保留 <|endoftext|>——不保留的话，长训练后模型会"忘记"怎么停；③ 采样逻辑与第 7 课完全等价（同种子同参数 → 同输出）。

03阶段二：奖励 = 验证器 + 格式约束

def reward_rlvr(answer_text, ground_truth):
    extracted = extract_final_candidate(answer_text, fallback=None)  # 关键：None
    if not extracted:
        return 0.0
    return float(grade_answer(extracted, ground_truth))

fallback=None 是唯一的改动：必须 \boxed{} 格式才给抽答案——隐性格式奖励：答案既要对、又要装在盒子里，奖励才是 1BRM §6.6。四个 rollout 的实测：

rollout奖励原因

The correct answer is \boxed{83}1.0 ✅对 + 有盒子
The final answer is 830.0 ❌对了但没盒子
We get \boxed{38}0.0 ❌有盒子但错了
R1 的教训DeepSeek-R1 也试过给中间步骤打分（process reward model），失败——只奖励最终答案正确性效果更好。BRM §6.6

04阶段三：rewards → advantages

奖励只说"这个 rollout 多好"，advantage 说"相对同组其他 rollout 多好"——一行公式BRM §6.7：

rewards[1, 1, 0, 0]
−组均值 ÷组标准差→
advantages[+0.87, +0.87, −0.87, −0.87]
图 1 · Aᵢ = (rᵢ − μ) / (σ + ε)。ε=1e-4 防除零。

三条性质，直接决定训练行为：

  1. 优势正 → 提升该 rollout 的生成概率；负 → 压制；≈0 → 几乎不动。梯度更新的方向和力度都由它缩放。
  2. 全组同分（全对或全错）→ 优势全 0 → 梯度全 0 → 本题不更新。太难的题（模型从不对）和太简单的题（模型总对）都学不到东西——GRPO 只在模型"有时对"的难度区发力。这就是为什么 base 模型 15% 的起点反而够用：采样 N 次，总有蒙对的时候。
  3. 标准化让不同题的信号量纲一致：不管这组是 2/4 对还是 7/8 对，优势幅度可比。
GR 的含义GRPO = Group Relative Policy Optimization："组相对"就是这一步——同一 prompt 采一组回答，组内互相比。基线（baseline）不是训出来的价值模型，就是这组自己的平均分。第 11 课说的"省掉价值模型"，省的正是这里。
工作联想书练习 6.1：给"对但没盒子"的回答 0.5 分（部分学分）——这就是给奖励塑形。下一章你会看到 DeepSeek-R1 真实用了格式奖励 + 语言一致性奖励等更精细的 shaping，思想同源。

05检索练习

一句话带走 Rollout = 一次完整采样（no_grad 版，留 EOS）；奖励 = 验证器 + boxed 格式门槛（0/1）；优势 = 组内标准化（同分零梯度，只在"有时对"的题上学习）。
