第 8 课 · Self-Consistency：少数服从多数

📖 BRM §4.6 ⏱ 25–35 分钟 🎯 收获：投票把 base+CoT 推到 52%，并看清推理时扩展的收益递减曲线

为什么学这个：上一课你让模型能给出不同答案了——现在的问题是怎么把"多次尝试"变成"更高准确率"。Self-consistency 的答案是投票。它是生产系统真实在用的技术（Claude 4 的并行采样），也是理解"推理时扩展收益曲线"的最佳案例——什么时候加算力划算、什么时候不划算，这直接回答你工作里的预算问题。

01核心思想

Self-consistency sampling（Wang et al., 2022）：同一道题，用温度+top-p 采样 N 个独立解答，抽取每个的最终答案，选出现次数最多的BRM §4.6。逻辑：正确的解法往往殊途同归——不同推理路径会汇聚到同一个答案；而错误各有各的错法，票数分散。

02实现：30 行

from collections import Counter

def self_consistency_vote(model, tokenizer, prompt, device,
                          num_samples=10, temperature=0.8, top_p=0.9, ...):
    short_answers = []
    for i in range(num_samples):                      # ① 采样 N 次
        answer = generate_text_stream_concat_flex(
            model, tokenizer, prompt, device,
            max_new_tokens=2048,
            generate_func=generate_text_top_p_stream_cache,  # 第 7 课的函数
            temperature=temperature, top_p=top_p)
        short_answers.append(
            extract_final_candidate(answer))          # ② 复用 ch3 抽取器
    counts = Counter(short_answers)

五个关键读数：

  1. 投票没有 CoT 不行（行 5–7：29~32%，还不如行 3 的 CoT 单次）。裸答案太短，采样多样性带来的噪声盖过了收益。先 CoT 再投票（行 9–11）才一路涨到 52%。
  2. 收益递减：n=3→5→10，准确率 42→48→52，耗时 212→453→863 分钟。票数翻倍，涨点减半。
  3. 纯采样不涨分（行 4 vs 行 1：15.2→17.8）：温度/top-p 只是多样性的旋钮，本身不是推理时扩展技术。
  4. 组合拳逼近训练效果：base+CoT+投票(n=10) = 52%，超过了官方 reasoning 模型贪心的 48.2%——不训练也能摸到推理模型的下沿，但花的时间是 4.7 倍。
  5. 推理模型也能再投票（行 12：48.2→55.2%）——方法正交可叠加。
工作决策框架看到"用推理时扩展换准确率"的报价时问三个问题：① 基线是什么（行 1 还是行 3）？② n 多大、在收益曲线的哪一段？③ 有没有可以并行的算力？——递减曲线后半段的每一分准确率都是重金买的。
⚠ 局限投票依赖"可抽取的短最终答案"（数值/符号）。开放性任务（写文案）没有众数可言——那要靠第 9–10 课的 self-refinement。BRM §4.6

04检索练习

一句话带走 Self-consistency = 温度采样 N 份 CoT 解答 + 答案众数投票。正确的推理殊途同归，错误的各自散开。base 15%→52%（配 CoT, n=10），但收益随 n 递减、成本线性涨。
