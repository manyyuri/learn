03① 抽取：找最后一个 \boxed{}

两个实现要点BRM §3.4, listing 3.4–3.5：

  • 取最后一个 \boxed（rfind）——模型中途可能写过草稿式的 boxed，最终答案在最后；
  • 括号要数嵌套：用 brace_depth 计数器配平 {}，否则 \boxed{\frac{14}{3}} 会在第一个 } 处截断。

没有 boxed 怎么办？extract_final_candidate 提供 fallback：默认 "number_then_full"——退而取文本中最后一个数字，再不行返回全文BRM §3.4。

为什么不用 LLM 来抽取？抽取是机械任务：确定性代码便宜、可复现、不会引入第二个模型的随机误差。判断"答案对不对"和"格式抽没抽对"是两回事——前者 LLM 真答错了，换 LLM 抽取也救不了。BRM §3.4 侧栏

04② 归一化：一千种写法，一种形式

同一个数，模型可能写成 \frac{14}{3}、14/3、$14/3$、(14)/(3)、2²…… normalize_text 把它们统一成"计算器风格"BRM §3.5, listing 3.6：

规则例子
剥 LaTeX 修饰\left( \right)、\( \)、$ 删掉
统一分数宏\dfrac、\tfrac → \frac → (a)/(b)
根号与乘号\sqrt{8} → sqrt(8)；\cdot → *
上标与度数2² → 2**2；90^\circ → 90
杂项千分位逗号、<|assistant|> 这类特殊 token、大小写

05③④ 符号等价与判分

字符串相等不够用：14/3 ≠ (14)/(3)（字符串），28/6 ≠ 14/3（形式）——但数学上相等。方案：SymPy 符号引擎BRM §3.6, listing 3.7–3.8：

def equality_check(expr_gtruth, expr_pred):
    if expr_gtruth == expr_pred:              # 快路径：字符串直接相等
        return True
    gtruth, pred = sympy_parser(expr_gtruth), sympy_parser(expr_pred)
    if gtruth is not None and pred is not None:
        try:
            return simplify(gtruth - pred) == 0   # 关键：差式化简为 0 ⟺ 等价
        except (SympifyError, TypeError):
            pass
    return False
  • sympy_parser 允许隐式乘法（2y = 2*y），解析时求值（2+3 → 5），并吞掉各类畸形输入（返回 None，超过 2000 字符的垃圾直接放弃）。
  • 判定等价的黄金判据：两式之差化简为 0。于是 0.5 与 1/2 → True；但 0.3333333333 与 1/3 → False（有限小数不等于无理分数——这是正确行为，不是 bug）。
  • 元组答案（如极坐标 (3, π/2)）：grade_answer 先按逗号拆成子式，逐项做 equality_check，全对才对BRM §3.7。

书的 16 个测试用例全部通过，包括 \frac{\sqrt{8}}{2} ≡ sqrt(2)、2² ≡ 2**2、90^\circ ≡ 90 这些刁钻格式BRM §3.7, listing 3.11。
