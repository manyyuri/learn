千金妆研习 · 参考文档 02

千金妆产品 & 工具清单

第 1 课的盘点任务用它 · 打印出来打勾 ✅

原则：先盘点手头已有的，缺什么补什么；新手阶段全部买平价即可（橘朵、花洛莉亚、UKISS、Canmake 这类百元内国货/日开架足够练手，手法比产品贵）。

①底妆

产品作用挑选要点
妆前乳填平毛孔、让底妆服帖干皮选保湿型，油皮选控油型
哑光粉底液瓷感肌的地基色号去专柜试在下颌线上，和脖子衔接为准
遮瑕（提亮色 + 肤色）盖瑕疵 + 面中提亮提亮色比肤色亮一度
哑光散粉定妆、压掉油光透明色最不容易出错
美妆蛋 / 粉扑上底妆打湿挤干后用，妆感最薄

②眉毛

产品作用挑选要点
眉笔（灰棕色）勾勒眉形、补空缺黑发/深棕发选灰棕，别选纯黑
染眉膏毛流感 + 统一眉色和眉笔同色系
螺旋眉刷晕染、梳顺很多眉笔尾部自带

③眼妆（核心预算区）

产品作用挑选要点
哑光大地色眼影盘眼窝铺色、眼尾加深必须有：浅米色 / 灰棕 / 深棕 三个哑光色
眼线胶笔（深棕）上眼线 + 下至线棕色比黑色柔和，更贴千金妆
眼线液笔（黑/棕）点泪痣、补内眼角极细笔尖
睫毛夹夹翘真睫毛贴合自己眼型弧度
睫毛膏（纤长款）刷真睫毛 + 下睫毛纤长优于浓密
假睫毛（仙子毛/太阳花款）+ 胶水大眼三件套的灵魂透明梗更隐形；先买 2–3 对练手
卧蚕笔 / 提亮笔画卧蚕亮面哑光米白或浅香槟

④修容 · 腮红 · 唇

产品作用挑选要点
灰调修容粉鼻影、下颌灰调才像阴影；红调修容会显脏
哑光高光 + 细闪高光面中提亮 / 鼻梁鼻尖盒型鼻用细闪那一块
低饱和腮红（奶粉色）若有若无的血色感上脸"看不太出来"就是对的
豆沙色唇泥/唇釉MLBB 唇干枯玫瑰 / 豆沙玫瑰色系

⑤工具 & 可选

产品备注
化妆刷套组（铺色刷/晕染刷/细节刷/斜角刷）眼妆至少 3 把：铺色、晕染、细节
棉签 + 卸妆水画错修正，新手用量很大
美瞳（灰棕 / 灰蓝，14.2–14.5mm）可选；放大虹膜，洋娃娃感来源
