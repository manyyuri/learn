hook 索引：谁注册了什么、何时生效

读完这一课，你手里有一张「20 个 hook 分类卡」——每个 hook 是什么、在哪一帧可用、跑在哪个时点。这张卡也是往后查源码的路标。

§0开场检索

§1三维坐标：渲染时点 × 可用帧 × 作用域

给每个 hook 定位需要三个维度（源码注释里的关键语义都在这三轴上）：

  • 声明时点：hook 是渲染期声明（在 agent 函数体里调用即完成注册），真正"跑"在别处——模型调用循环 / 生命周期缝 / 工具执行。
  • 可用帧：根 agent 帧 kind:'agent' vs 委派帧 kind:'subagent'。subagent 帧禁 useModel（模型在 useSubagent 定义上声明）、usePersistentState（持久状态是实例级的）、useSandbox（delegate 共享父环境）。
  • 作用域：submission 级（model/thinking/compaction，提交开始时读一次）vs instance 级（持久状态、会话存储）vs render 级（指令、能力集）。

§2组合类：给 agent 配能力

hook注册什么要点（源码契约）
useModel(model, opts?)agent 的模型 + thinkingLevel/compaction每次 render 恰好一次；submission 级；subagent 帧禁用
useInstruction(text)追加指令文本落在 return 指令之后、按调用顺序；低层逃生舱，无身份无追踪
useTool(def)一个可调用动作名字全局唯一；可条件挂载；每轮从零声明

§3状态与数据类：记忆与输出

hook语义硬规则
usePersistentState(name, default)读「截至本渲染」的持久值，返回 setter读是渲染快照；写是静默的——不 wake agent、不中途重渲染；值须 JSON；用 updater 函数写避免基于过期快照
useInitialData<T>()读实例创建时的结构化数据创建期 schema 静态校验一次；已有实例忽略新数据
useDataWriter(name, schema?)声明一个客户端数据通道，返回只写函数单向出、模型看不见；名字是响应的客户端身份，必须无条件声明
useDelivery()读「当前在模型面前」的那条消息是个游标：随新消息到达而前进；让工具不必依赖模型回显参数
useDispatchMessage()绑定到本实例的派发器只收 message，无创建 data/uid（实例已存在）

一条值得刻进脑子的分界：持久状态是「你的代码能读能改」的部分，其余一切活在转录文本里。跨轮状态、一次性工作守卫（gathering→drafting）、解锁能力——都是它。

§4生命周期类：响应与收件两条缝

一次响应的真实时序（源码注释口径）：

useResponseStart响应真起点 · 首次模型调用前 · 早于 agentStart
↓ 收到一条投递消息（输入已持久）
useAgentStart收件缝 · 模型首 turn 前 · async，适合加载数据
↓ [render → 模型调用 → 工具] 循环，可多轮
useAgentFinish执法缝 · 模型无更多工具调用、即将收尾检查 ctx.response.toolCalls，工作没完就 ctx.append 让它回去
↓ 若被 append，回到循环
useResponseFinish真终点 · 所有 agentFinish 循环落定、输出 flush 后
  • response 类：每个响应恰好一次的真起点/真终点（不论收了多少条消息）。返回对象深合并到响应的 metadata——给客户端打时间戳、token 用的信封字段。
  • agent 类：每条投递消息都跑（agentStart 收件、agentFinish 执法）。至少执行一次：完成的工作持久提交不重复，打断的会重试——"绝不能做两次"的事（发邮件、下单）要用持久状态守卫。

§5第 4 族：自定义 hook

以 use 开头的普通函数，内部调任意 built-in hook——因为帧按调用顺序扁平收集，自定义 hook 等价于「展开写」。大 agent 靠它保持可读，能力靠它在 agent 间复用：一个打包好工具+技能+指令的 useGitHub() 写一次，到处挂。
guide/agent-hooks.md（Custom hooks）· runtime/src/hooks/frame.ts

§6本课自测

本课的胜利：给每个 hook 贴上一张标签——组合/状态/生命周期/自定义 × submission/instance/render 作用域 × agent/subagent 帧。遇到「这个 hook 为什么不生效」，先对着这张卡查它跑在哪个时点。
